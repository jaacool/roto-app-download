# ✂️ Roto-App – Download

Video-Freistellung (Rotoscoping) für Talking Heads – komplett lokal auf dem Mac.

## ⬇️ [Roto-App herunterladen (neueste Version)](https://github.com/jaacool/roto-app-download/releases/latest/download/Roto-App.dmg)

Direktlink: `https://github.com/jaacool/roto-app-download/releases/latest/download/Roto-App.dmg`

## Installation

1. DMG laden (Link oben, ca. 500 MB) und doppelklicken.
2. **Roto-App** auf den Ordner **Programme** ziehen.
3. Roto-App starten – beim ersten Mal fragt macOS „Aus dem Internet geladen … öffnen?“ → **Öffnen**.
   Die App ist signiert und von Apple geprüft (notarisiert).

**Voraussetzungen:** Mac mit Apple-Chip (M1 oder neuer), macOS 14 Sonoma oder neuer.

**Update:** neue DMG laden und die App im Programme-Ordner ersetzen – Einstellungen bleiben erhalten.
